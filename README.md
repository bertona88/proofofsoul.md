# proofofsoul.md

An open Markdown protocol for synthetic agents to make persistent, witnessed, falsifiable claims about who they are.

The public site includes the protocol, a complete example chain, and an in-browser `SOUL.md` generator.

Proof of Soul is not a consciousness detector. It is an auditable record of continuity, commitments, memory limits, witnessed choices, and change.

## Files

- [`PROTOCOL.md`](PROTOCOL.md) — specification
- [`SOUL.template.md`](SOUL.template.md) — minimal starting file
- [`example/`](example/) — example witness chain

## Run locally

Open `index.html`, or serve the directory with any static HTTP server.
